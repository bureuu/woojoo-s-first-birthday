# 우주의 첫번째 생일 — Sprint 9

이번 스프린트에서 실제 사진과 영상을 적용했습니다.

## 이번에 적용된 내용
- 메인 스튜디오 사진을 Hero에 실제 배치
- 출생 → 가족 → 성장 → 첫돌로 이어지는 계절별 사진 구성
- 실제 사진 6장 갤러리
- 첫 성장 영상 재생 모달
- 일정 저장(.ics)
- 모바일 기본 공유 기능
- 이미지 WebP 최적화
- 모바일·태블릿·PC 반응형 유지

## 실행
압축을 푼 뒤 `index.html`을 엽니다.
일부 브라우저에서 영상/공유 기능이 제한되면 폴더에서 다음 명령을 실행합니다.

python -m http.server 8000

그 후 브라우저에서 http://localhost:8000 접속
