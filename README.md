# 우주의 첫 번째 생일 · Sprint 11 Review Edition

## 주요 변경 사항

- Hero 대표 사진은 고정 유지
- `오늘의 우주` 카드에 방문할 때마다 랜덤 사진과 문구 표시
- 성장 영상 섹션을 프리미엄 앨범 커버 형태로 리디자인
- 작은 본문 글자와 행간을 확대해 모바일 가독성 개선
- 카드 간격, 그림자, 라운드 및 모바일 여백 정리
- 버튼과 사진 카드에 자연스러운 터치 피드백 적용
- 원본 사진 파일을 손대지 않고 매우 약한 웹 표시 톤 통일 적용
